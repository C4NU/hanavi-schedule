# 주간 통합 시간표 학생증 레이아웃 및 이리야 전용 디자인 기술 스펙

본 문서는 주간 통합 시간표 화면 우측의 학생증 카드 더미 배치 아키텍처 및 이리야(`iriya`)의 전용 MAIVI 학생증 디자인 구현 스펙에 대해 설명합니다.

---

## 1. 아키텍처 및 구조 개요
주간 통합 뷰(`viewMode === 'weekly'`)가 활성화될 때 시간표와 학생증 리스트를 유기적으로 결합하여 화면에 표시합니다.

### 1.1 데스크톱 레이아웃 (`min-width: 1024px`)
- **2열 구조**: `weeklyContentContainer`를 사용하여 2열 플렉스박스 레이아웃을 구성합니다.
  - **좌측 (`weeklyTimetableLeft`)**: 주간 시간표가 차지하며 `flex: 1` 및 `min-width: 0`을 지정하여 너비가 유연하게 줄어들도록 조정합니다.
  - **우측 (`weeklyCardsRight`)**: 7명의 멤버 학생증 카드가 세로 방향 스택 구조로 정렬됩니다.
- **세로 지그재그 배치 및 겹침 완화**: 
  - 각 카드에 `margin-bottom: -110px`을 지정하여 기존 대비 카드가 2배 이상 더 잘 보이도록 겹침 강도를 완화했습니다.
  - 홀수 인덱스는 우측으로 25px(`translateX(25px)`), 짝수 인덱스는 좌측으로 25px(`translateX(-25px)`) 치우치게 배치하여 지그재그 배치를 통한 시각적 답답함을 해소하고 입체적인 리듬감을 구현했습니다.
- **기울기 오프셋**: 7개 카드 각각에 서로 다른 회전 각도(`[2.5, -3.5, 1.5, -2, 3, -1.5, 2]`)를 설정하여 자연스럽게 흐트러진 효과를 연출합니다.

### 1.2 모바일 레이아웃 (`max-width: 1024px`)
- **하단 가로 스크롤 및 상하 지그재그**: 
  - 화면 폭이 좁은 모바일 기기에서는 `flex-direction: column`으로 레이아웃을 전환하여 학생증 카드를 시간표 하단에 가로 방향(`overflow-x: auto`)으로 나열합니다.
  - 가로 방향으로 `margin-right: -190px`을 주어 조밀하면서도 가독성 있게 겹쳤습니다.
  - 홀수 인덱스는 하단으로 12px(`translateY(12px)`), 짝수 인덱스는 상단으로 12px(`translateY(-12px)`)로 번갈아 배치하는 물결형 지그재그 배치를 통해 모바일 화면에서도 역동적인 느낌을 연출했습니다.
- **반응형 스케일링**: 데스크톱에서는 0.65배 크기로, 모바일 기기에서는 0.58배 크기로 축소 렌더링되도록 디자인 가독성을 고려해 재조정했습니다.

---

## 2. CSS Custom Properties 기반 변수 연동
React 인라인 스타일과 미디어 쿼리가 깔끔하게 연동될 수 있도록 CSS Custom Properties를 도입했습니다.
- `--rotate-deg`: React 컴포넌트 레벨에서 계산된 인덱스별 고유 회전 각도를 CSS로 바인딩합니다.
- `--offset-x` / `--offset-y`: 각각 데스크톱 좌우 지그재그, 모바일 상하 지그재그를 제어하는 픽셀 값 오프셋 변수입니다.
- `--scale-factor`: 데스크톱(`0.65`)과 모바일(`0.58`) 해상도 미디어 쿼리에 따라 동적으로 스케일 요소가 재정의됩니다.
- **호버 애니메이션**:
  - 마우스를 올리거나(Hover) 모바일에서 터치(Active)할 때 `--scale-factor`가 각각 0.78/0.7로 확장되며, 지그재그 오프셋이 초기화(`translateX(0) / translateY(-20px)`)되고 0도로 돌아와 위쪽으로 떠오르는 마이크로 애니메이션을 제공합니다.

## 3. 이리야 전용 MAIVI 학생증 디자인
이리야(`iriya`) 멤버의 학생증은 MAIVI 유닛 컨셉에 맞춰 완전한 커스텀 테마로 분기 렌더링됩니다.

### 3.1 세부 디자인 스펙
- **헤더 바**: 어두운 회색/검정 계열 배경색(`bg-[#282828]`), `Cinzel` serif 폰트의 `STUDENT ID CARD` 텍스트, 그리고 우측 끝의 재생 버튼 모양 `▶` 심볼 적용.
- **바디 배경**: 내추럴 베이지색 계열(`bg-[#e8e4db]`).
- **아바타 사진 영역**: 얇고 투명도 있는 검정 테두리(`border-[#282828]/60`) 적용.
- **ID 번호 배지**: `ID No. 20251122-1` 이 각인된 블랙 배지 및 그 옆에 [MAM] 로고를 상징하는 하트 심볼 SVG 인라인 렌더링.
- **세부 항목 필드**: 
  - `Name` (Iriya Noir), `Birth` (19th, September), `Unit` (Maivi of Hanavi Universe) 텍스트 명시 및 가로 구분선 가미.
  - 가치 값 텍스트에 하나비 영문 전용 서체인 `Libre Caslon Display`를 적용하여 폰트 아이덴티티를 일원화했습니다.
- **친필 서명 및 워터마크**:
  - `Signature` 영역 우측에 구글 필기체 폰트인 `Caveat` 폰트를 입힌 필기체 서명 `iriya` 출력.
  - 서명 레이어 뒷배경에 연한 투명도의 `May Girls High School` 텍스트 워터마크를 우측 정렬하여 실물 디자인을 입체적으로 고해상도 재현.
