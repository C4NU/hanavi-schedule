# 씨미(Ci.me) 다시보기 자동화 및 UI 연동 가이드

이 문서는 씨미 플랫폼의 다시보기(VOD) 데이터를 자동으로 수집하고, 시간표 UI에 연동하는 방식에 대해 설명합니다.

## 1. 개요
씨미 플랫폼은 공식 OpenAPI에서 아직 VOD 목록 조회 기능을 제공하지 않습니다. 따라서 본 프로젝트에서는 **HTML 스크래핑** 방식을 사용하여 최신 다시보기 데이터를 수집합니다.

## 2. 자동화 프로세스 (Cron Job)
- **API 경로**: `/api/cron/update-cime-replays`
- **실행 주기**: 매일 정각 (Vercel Cron 설정 권장)
- **작업 내용**:
    1. 현재 활성화된 주간 스케줄 정보를 조회합니다.
    2. 등록된 멤버들의 씨미 채널 페이지(`https://ci.me/@handle/vods`)를 순회하며 HTML을 가져옵니다.
    3. 정규표현식을 통해 VOD ID, 방송 날짜, 방송 카테고리를 추출합니다.
    4. 추출된 날짜와 스케줄표의 날짜가 일치하고, 아직 링크가 등록되지 않은 항목을 찾아 업데이트합니다.

## 3. UI 연동 및 디자인
- **ScheduleCell**: 
    - 다시보기 링크가 존재하는 경우, 하단에 디바이더와 함께 **방송 카테고리** 태그를 표시합니다.
    - 우측에는 기존의 **제보(메모) 개수** 배지를 함께 배치하여 정보 밀도를 높였습니다.
- **Admin 도구**:
    - `InfoModal` 내에 관리자 전용 섹션을 추가하여, 크론잡을 수동으로 즉시 실행할 수 있는 버튼을 제공합니다.

## 4. 데이터 구조 (Supabase)
`schedule_items` 테이블에 다음 필드가 사용됩니다:
- `video_url`: 다시보기 링크 (YouTube 또는 Ci.me)
- `category`: 방송 카테고리 (예: 저스트 채팅, 게임 이름 등)

## 5. 주의사항
- **스크래핑 의존성**: 씨미 공식 사이트의 HTML 구조가 변경될 경우 파싱 로직(정규표현식) 업데이트가 필요할 수 있습니다.
- **보안**: 크론 API는 `CRON_SECRET` 헤더 검증을 통해 보호됩니다.
